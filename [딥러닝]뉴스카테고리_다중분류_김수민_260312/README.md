# 뉴스 카테고리 다중분류 프로젝트 보고서 

## 1. 프로젝트 목적
- 자연어 데이터 전처리 및 TF-IDF 벡터화 과정 이해  
- 다양한 머신러닝 모델(8종)의 성능 비교 및 보팅(Voting) 기법 적용  
- 딥러닝 모델(Dense, RNN)과 머신러닝 모델의 성능 차이 분석  
- 단어장 크기(Vocabulary Size) 변화가 분류 성능에 미치는 영향 확인  

---

## 2. 데이터셋 정보
- **데이터셋**: Reuters News Dataset  
- **클래스 수**: 46개  
- **훈련 데이터**: 8,982개  
- **테스트 데이터**: 2,246개  

---

## 3. 실험 설계 및 수행 과정

### 3.1 전처리 및 벡터화
- 정수 시퀀스로 이루어진 데이터를 실제 단어로 복원(Decoding)  
- `CountVectorizer`와 `TfidfTransformer`를 사용하여 TF-IDF 벡터로 변환  

### 3.2 실험 변수
- **Vocabulary Size**: None(전체 단어 사용), 5,000, 2,000  
- **적용 모델**:  
  - 머신러닝: MultinomialNB, ComplementNB, Logistic Regression, LinearSVC, Decision Tree, Random Forest, Voting  
  - 딥러닝: Dense (MLP), RNN (LSTM)  

---

## 4. 주요 실험 결과

| 모델 분류 | 모델명 | 단어장 크기 | Accuracy | F1-Score |
|-----------|--------|-------------|----------|----------|
| 최우수 모델 | LinearSVC | 2,000 | **0.8317** | **0.8246** |
| 머신러닝 2위 | Voting | 2,000 | 0.8236 | 0.8142 |
| 딥러닝 (Dense) | Dense (MLP) | 10,000 | 0.7707 | 0.7350 |
| 딥러닝 (RNN) | LSTM | 10,000 | 0.5841 | - |

---

## 5. 결론 및 인사이트
- **최적 모델**: 단어장 크기를 2,000개로 제한했을 때 **LinearSVC**가 약 83.17% 정확도로 최고 성능을 기록  
- **ML vs DL**: 로이터 데이터셋에서는 복잡한 딥러닝 모델(RNN)보다 **TF-IDF 기반 머신러닝 모델**이 더 우수  
- **실험 최적화 중요성**: 동일한 모델이라도 전처리 방식(단어장 크기)에 따라 성능 편차 발생 → 반복적 실험과 파라미터 탐색 필수
